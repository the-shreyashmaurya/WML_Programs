# WML Programs 

This repository contains a collection of **WML (Wireless Markup Language)** programs, demonstrating various functionalities and features of WML.   

## 📂 File Descriptions  

- **1_Hello_world.wml** – Displays a simple "Hello, World!" message.  
- **2_anchor_tag.wml** – Demonstrates the use of anchor tags for navigation.  
- **3_img_tag.wml** – Illustrates embedding images using the `<img>` tag.  
- **4_input.wml** – Shows how to create input fields for user data entry.  
- **5_link.wml** – Explains linking to external resources.  
- **6_a_tag.wml** – Another example of using anchor tags.  
- **7_center.wml** – Demonstrates centering content on the page.  
- **8_timer.wml** & **9_timer.wml** – Examples of implementing timers.  
- **10_diff_font.wml** – Explores different font styles and sizes.  
- **11_onEvent.wml** – Handles events using the `onEvent` attribute.  
- **12_footer.wml** – Implements a footer section in WML.  
- **13_table.wml** – Creates tables to organize data.  
- **14_template.wml** – Utilizes templates for consistent layouts.  
- **15_checkbox.wml** – Introduces checkboxes for user selections.  
- **16_Dropdown.wml** – Implements dropdown menus for options.  
- **test.wml** – A test file for experimental purposes.  

### 🖼️ Assets  

- **test.jpg** – An image file used in conjunction with `3_img_tag.wml`.  

## 🚀 Getting Started  

To view and test these WML files:  

### 1️⃣ Set Up a WML-Compatible Environment  
- Use a WML emulator or a compatible mobile device that supports WML.  

### 2️⃣ Deploy Files to a WAP Server  
- Ensure the server is configured to serve WML content with the correct MIME types (`text/vnd.wap.wml`).  

### 3️⃣ Access via WAP Browser  
- Navigate to the URL where the WML files are hosted to view them.
